# DeadZone Statusbar Glass UI Design System

## Colors
Use the closest existing theme tokens. Do not add heavy dependencies.

Suggested palette:
- Background: #020812 / #071225 / #0B1730
- Card glass: rgba(16, 32, 62, 0.62)
- Card border: rgba(89, 170, 255, 0.32)
- Accent blue: #3A7BFF
- Accent cyan: #21D7E8
- Success green: #39E99B
- Text primary: #F5F8FF
- Text secondary: #AEB9D2
- Divider: rgba(180, 210, 255, 0.12)

## Layout
- Screen padding: 20–24dp
- Card radius: 24–32dp
- Small control radius: 14–18dp
- Bottom sheet radius top: 28–34dp
- Preview pill radius: 22–28dp
- Quick section grid: 2 columns on phone, or adaptive

## Components
- GlassCard
- SectionHeader
- PreviewStrip
- StatusIconChip
- SettingRow
- SegmentedControl
- SliderRow
- ColorDot
- OptionTile
- QuickSectionTile
- FriendlySnack

## Motion
- Screen transition: 220ms
- Bottom sheet: 260ms
- Tile press scale: 0.98
- Drag tile scale: 1.05
- Save feedback: subtle check animation

## Copy rules
Use simple user-friendly labels.
Do not show internal technical keys.
